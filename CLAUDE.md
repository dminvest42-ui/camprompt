# Правила работы в репозитории CamPrompt

Читается любым агентом, работающим в `~/projects/teleprompter/`. Контекст проекта и карта документации — [docs/AGENT_ONBOARDING.md](docs/AGENT_ONBOARDING.md).

---

## Что это за проект

**CamPrompt** — нативный macOS-телесуфлёр: текст едет под вырезом камеры MacBook, запись видео и звука внутри приложения. Swift 5.9+, SwiftUI + AppKit, AVFoundation, SwiftPM, ноль внешних зависимостей, macOS 14+. Инструмент личный: один пользователь, интерфейс русский, сети и телеметрии нет.

---

## Сборка: только через GitHub Actions

Среда разработки — Linux, swift-тулчейна для macOS нет. **Не пытаться** собрать локально, поставить Swift или найти обходной путь.

    git push origin main            # → сборка .app + .dmg артефактом, ~45 с
    git tag -a vX.Y.Z && git push origin vX.Y.Z   # → GitHub Release с .dmg
    gh run watch <id> -R dminvest42-ui/camprompt --exit-status

Компиляция — единственная автоматическая проверка. Геометрия панели, TCC-диалоги, цвета в светлой/тёмной теме, фокус ввода, курсоры, реальные камеры — **только руками на живом Mac**. Поэтому каждый ответ по правкам в этих зонах обязан заканчиваться коротким списком «что проверить».

## Git

- Почта коммитов — **только** `dminvest42-ui@users.noreply.github.com`, иначе GitHub отклоняет пуш (GH007). В репозитории она настроена, но при коммите всё равно давать `-c user.email=…`.
- Папка под cron `projects-auto-sync` (каждые 5 минут `git add -A` + коммит «server auto-sync» + push). Отсюда: **не пользоваться `git stash`**, писать файлы и сразу коммитить самому. Если увидел чужой коммит «server auto-sync» — это бот, не человек.

## Репозиторий публичный — это главное ограничение

`dminvest42-ui/camprompt` — **единственный публичный репозиторий аккаунта**, все остальные приватные. Публичность выбрана ради бесплатных macOS-раннеров ([D-006](docs/DECISIONS.md#d-006-сборка-только-на-macos-раннере-github-actions)).

Опасность не в коде, а в автоматике: cron `projects-auto-sync` делает `git add -A` + push **каждые 5 минут, без человека**. Файл, случайно оказавшийся в папке, уезжает в открытый доступ сам.

**Чего здесь не должно быть никогда:** ключей и токенов, `.env`, приватных ключей и сертификатов, дампов и выгрузок, персональных данных клиентов, адресов и паролей серверов, содержимого рабочих vault'ов. Черновики и временные файлы — в каталог-черновик вне `~/projects/`, не сюда.

**Барьер** (`scripts/git-hooks/pre-commit`, ставится `bash scripts/setup-git-hooks.sh`):
1. `gitleaks protect --staged` по `.gitleaks.toml` — **блокирует** коммит при находке;
2. чёрный список путей (`.env`, `*.pem`, `*.key`, `id_rsa`, `credentials.json`, `service_account*.json`) — **блокирует**;
3. проверка ссылок в документации — только предупреждение, авто-синк из-за неё не встаёт.

Сорванный авто-коммит — штатный исход: `projects-auto-sync` пишет `commit=fail` и продолжает работать. Лучше так, чем секрет в открытом доступе. Хук живёт в `.git/hooks/` и **не переносится при клонировании** — после `git clone` его надо поставить заново.

Аудит истории на 2026-09-22 (12 коммитов, все ветки и теги): утечек нет — [D-019](docs/DECISIONS.md#d-019-публичный-репозиторий-с-барьером-на-коммите).

## Правила кода

1. **Ноль внешних зависимостей.** Новая зависимость = новый риск, который нечем проверить. Добавление обсуждается отдельно и фиксируется решением в [docs/DECISIONS.md](docs/DECISIONS.md).
2. **`AVCaptureSession`: пресет только после добавления входов.** Любая проверка возможностей сессии без входов врёт. [D-011](docs/DECISIONS.md#d-011-sessionpreset-выставляется-после-добавления-входов)
3. **Тихих отказов не бывает.** `canAddInput == false`, пустое соединение, неудачная настройка — всё это идёт в `lastError` и на экран. Запись не стартует без активного видеосигнала. [D-012](docs/DECISIONS.md#d-012-отказ-входа-виден-пользователю-запись-не-стартует-без-видеосигнала)
4. **`Slider(step:)` — не использовать** на диапазонах больше нескольких десятков значений: macOS рисует засечку на каждый шаг. Снап делать в `Binding`. [D-013](docs/DECISIONS.md#d-013-шаг-ползунка--в-binding-а-не-в-sliderstep)
5. **Внутри панели суфлёра нет системных цветов.** Ни `.ultraThinMaterial`, ни `Color.primary/.secondary` — тема системы не имеет отношения к цветам, которые выбрал пользователь. [D-015](docs/DECISIONS.md#d-015-фон-плашки-управления--сплошной-тёмный-не-ultrathinmaterial)
6. **Прокручиваемый `Text` — всегда с `.fixedSize(horizontal: false, vertical: true)`.** Иначе обрезается многоточием. [D-009](docs/DECISIONS.md#d-009-текст--одна-text-нода-со-сдвигом-не-scrollview)
7. **Новая настройка** = свойство с `didSet` в `SettingsStore` + значение по умолчанию + строка в таблицу [ARCHITECTURE §8](docs/ARCHITECTURE.md#8-настройки-ключи-userdefaults) + элемент в поповер. Влияет на размер панели → `applyPanelGeometry()`; на стиль окна → `reloadPanelIfVisible()`.
8. **Правки в `PrompterView`** помнить: у панели своя иерархия `NSHostingView`, `@EnvironmentObject` туда не долетает — зависимости передавать конструктором.
9. **AVFoundation на macOS ≠ на iOS.** `supportedOutputSettingsKeys(for:)`, `availableVideoCodecTypes` и часть других API есть только на iOS — сборка упадёт с `is unavailable in macOS`. Настройки записи, которые Mac не примет, вызывают `NSException`, а Swift её не ловит: любой вызов `setOutputSettings` — только через `CPTryObjC` и с запасной ступенью. [D-020](docs/DECISIONS.md#d-020-качество-записи-hevc-с-потолком-битрейта-и-ступенчатый-откат)
10. Комментарии — по-английски, как в существующем коде; тексты интерфейса и документация — по-русски.

|---|---|

Ссылки между документами — обычные относительные markdown-ссылки: репозиторий читается на GitHub, где `[[wikilinks]]` не работают. Wikilinks уместны только в vault'ах Обсидиана (`my_system`, память агента).

Перед коммитом документации прогнать проверку ссылок и якорей:

    python3 scripts/check_docs_links.py

## Чего не делать

- Не собирать локально и не ставить Swift на сервер.
- Не пользоваться `git stash` в этой папке (cron-синк).
- Не добавлять зависимости, телеметрию, сетевые вызовы без отдельного решения.
- Не рефакторить «заодно»: проверить поведение нечем, цена ошибки — цикл через живого человека.
- Не обещать, что поведенческая правка работает, пока её не подтвердил человек на Mac. Формулировка — «собралось, проверить нужно вот это».
